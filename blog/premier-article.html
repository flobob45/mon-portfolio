Construire un portfolio avec Claude Code

Quand j'ai décidé de créer mon portfolio, je voulais quelque chose de simple : du HTML, du CSS et du JavaScript vanilla. Pas de framework, pas de bundler, juste les fondamentaux. Et pour m'accompagner dans cette démarche, j'ai utilisé Claude Code.

Pourquoi un site statique ?

Les frameworks modernes sont puissants, mais pour un portfolio personnel, ils ajoutent une complexité inutile. Un site statique se déploie partout, se charge instantanément et ne nécessite aucune maintenance serveur.

La simplicité est la sophistication suprême. — Léonard de Vinci

Le rôle de l'IA dans le processus

Claude Code m'a aidé à structurer le projet dès le départ : architecture des fichiers, conventions de nommage, CSS custom properties pour la cohérence visuelle. Chaque décision de design a été discutée et itérée.

Ce que j'ai appris

  • L'importance du mobile-first dans le design CSS
  • L'utilisation des CSS custom properties pour un thème maintenable
  • Comment structurer du JavaScript vanilla proprement
  • L'accessibilité avec les attributs aria-*

Prochaines étapes

Ce portfolio va continuer d'évoluer. J'y ajouterai mes futurs projets et des articles sur mes apprentissages en DevOps et en intelligence artificielle.
